# Phase 5 — Release and demo

## Goal

Polish, deploy, prove the approved real transaction, and submit before the deadline.

## P0 release checklist

- Responsive UX plus loading, empty, error, timeout, and retry states.
- Public Vercel URL and public GitHub repository with passing CI.
- Final README explains Pollar integration and honest limitations.
- Mainnet access confirmed; exact destination/cost reviewed; owner explicitly approves transaction.
- Execute the minimal approximately 1 USDC transaction and record explorer hash/result.
- Rehearse and record/live-present a demo no longer than three minutes.
- Prepare submission links, screenshots, fallback video, and transaction evidence.

## Gate

Fresh-browser smoke test passes, all records are synthetic, no secrets appear in code/client/logs,
production configuration is verified, and the full story fits comfortably under three minutes.
No financial step proceeds on implicit or earlier blanket approval.
